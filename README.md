# .github

Repositório de apresentação da organização [LifeFlowV](https://github.com/LifeFlowV).

O arquivo [profile/README.md](profile/README.md) define o conteúdo exibido no perfil público da organização após sua integração à branch padrão.

## Manutenção

- Mantenha a apresentação em português e coerente com os repositórios da organização.
- Diferencie funcionalidades presentes no código de propostas de produto.
- Confira tecnologias, links e evidências antes de atualizar o status; informe a data e os limites da verificação.
- Proponha mudanças por branch e pull request. Não inclua segredos nem dados pessoais.

As instruções para executar e testar cada aplicação ficam nos respectivos repositórios.
